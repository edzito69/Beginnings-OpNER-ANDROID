# Beginnings-OpNER-ANDROID
Beginnings OpNER brings EarthBound Beginnings Remake to Android with portrait and landscape gameplay, touch and gamepad controls, pinch zoom, save states, CRT filters, fast-forward and rewind. Created by Edzito for the ROM hack by the EBBR Team and PK Hack. An fully independent, unaffiliated project. No ROM is included.
